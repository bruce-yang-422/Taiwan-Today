隱私權政策

最後更新：2026 年 9 月 21 日 · 維護者：Bruce Yang

你的紀事、待辦、捷徑與設定保存在自己的裝置。台灣今日曆不設帳號，不加入廣告或使用行為追蹤，也不將這些內容上傳給開發者。

本政策適用於「台灣今日曆 Taiwan Today」瀏覽器插件，以及官網 today.stack-base.com 的紀事轉檔工具。

「在本機處理資料」與「將資料上傳給開發者」是兩回事。插件會讀取、使用及保存你主動提供的內容，因此不能說它完全不處理使用者資料；但這些本機內容不會因匯入、儲存或顯示而自動傳送給開發者。依 Chrome 線上應用程式商店的資料政策說明，僅在裝置上處理或儲存資料，也需要揭露處理方式。

1. 哪些資料會留在裝置上？

插件會儲存你新增或匯入的個人／家族紀事、待辦與完成狀態、捷徑名稱與網址、自訂圖示、外觀與內容設定，以及公共資料快取與更新狀態。這些資料用來顯示你的新分頁、保留操作結果及檢查公共資料是否需要更新。

個人識別資訊：由你自行提供的紀事內容

你可以在紀事標題、摘要、分類或待辦中填入姓名、小孩名字、生日或其他可識別個人的資訊。例如「小明的生日」會作為你匯入的紀事保存在本機，並在對應日期顯示。這些內容由你自行決定是否提供；插件不要求註冊、填寫真實姓名、電子郵件、地址或身分證字號，也不會自動從帳戶或其他網站取得這些資訊。

文字、圖片與超連結：你輸入或匯入的內容

插件會處理紀事文字、待辦文字、來源連結、捷徑名稱與網址，以及你自行匯入的捷徑圖示。這說明了「網站內容」類別中可能涉及的文字、圖片及超連結的實際來源與用途；並不代表插件會擷取你正在瀏覽的網站、讀取其他分頁、錄音或錄影。內建及更新下載的公共歷史、語錄和日曆資料，來自本專案的公開資料檔。

插件使用瀏覽器的 chrome.storage.local；一般網頁開發預覽使用 localStorage，兩者資料各自獨立。目前不提供跨裝置雲端同步。

插件不讀取整份瀏覽紀錄、其他分頁內容、Google 帳戶、聯絡人或位置。搜尋文字僅用於你送出的搜尋，不另外保存成插件搜尋紀錄。

2. 為什麼需要這些權限？

  • storage：保存前述本機資料，並同步同一瀏覽器中的插件分頁。
  • favicon：透過 Chrome 的網站圖示功能顯示捷徑圖示，不用來蒐集瀏覽紀錄。
  • GitHub Raw 選用連線權限：僅在你允許後，下載公開日曆、歷史及語錄 JSON；不授權仍可使用隨插件附帶的資料。

3. 什麼時候會連線？

公共資料自動更新預設關閉。你按「立即更新」，或授權並啟用每日檢查後，插件才會向 raw.githubusercontent.com 取得本專案的更新清單與公共 JSON。更新請求不附帶個人紀事、待辦、捷徑、設定、Cookie 或來源頁面資訊。服務提供者仍會收到建立連線所需的 IP 位址等技術資訊，並依其隱私政策處理。

你可在「設定 → 資料管理」關閉自動檢查，也可從瀏覽器的擴充功能管理頁撤回網站存取權限。關閉所有插件新分頁後，插件不會在背景下載資料。

使用 Google 搜尋或「深入了解」時，查詢文字或紀事關鍵字會送至 Google。點擊捷徑、Google 應用程式、來源網址或其他外部連結時，瀏覽器會開啟該網站；你的後續操作由該網站依自己的政策處理。Google 應用程式選單只是網站連結，不會讀取你的 Google 帳戶資料。

4. 官網轉檔會上傳檔案嗎？

不會。你選取的 CSV、XLSX、ODS 檔案在自己的瀏覽器記憶體中解析、驗證與預覽，JSON 也由瀏覽器直接產生下載。工具不將檔案內容傳給伺服器，也不把檔案內容寫入官網的本機儲存。重新整理或關閉工具頁面即可清除本次預覽；下載的檔案則由你自行保存或刪除。

官網程式未加入分析追蹤、廣告或追蹤 Cookie。官網託管於 GitHub Pages；依 GitHub Pages 說明，網站訪客的 IP 位址會為安全目的被記錄與保存。這不包含轉檔工具在本機處理的檔案內容。詳見 GitHub 隱私聲明。

5. 如何備份、刪除或停止使用？

本機紀事、待辦、捷徑與設定會持續保留，直到你刪除、取代或清除相關儲存資料；不會因跨日自動清空。不使用個人紀事或待辦功能，也可以使用日曆的其他功能。

可在插件中刪除待辦與捷徑；個人紀事可先「匯出目前紀事備份」，再匯入其他檔案取代，或匯入空陣列 [] 清空。這只影響個人紀事，不會刪除台灣或國際等公共歷史。

移除插件會清除其本機儲存資料；一般網頁開發預覽的資料可由瀏覽器清除此網站資料。你已下載的 JSON、表格與備份不會跟著刪除，請自行管理。開發者沒有你的本機資料副本，無法代為復原。

6. 資料分享與安全

個人紀事、待辦、捷徑及設定的處理僅用於你看得到的插件功能。插件不將這些本機內容上傳給開發者，開發者無法透過插件遠端查看，也不出售或用於廣告、使用者輪廓分析或追蹤。此用途限制依循 Chrome 線上應用程式商店的 Limited Use 要求。

你主動搜尋、開啟外部連結或公開分享備份時，相關文字、網址或分享內容可能交由第三方處理，詳見第 3 節；這與插件自動上傳本機資料不同。本機儲存不代表額外的加密保管庫；能存取你裝置或瀏覽器設定檔的人，可能接觸這些資料。

7. 政策更新與聯絡方式

功能或資料處理方式改變時，會更新本頁與上方日期；需要新的瀏覽器權限時，仍須經過瀏覽器授權。
