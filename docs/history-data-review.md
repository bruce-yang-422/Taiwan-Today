# 歷史紀事資料整理紀錄

整理日期：2026-09-21。

`data/history-taiwan.json / data/history-world.json` 共 150 筆（台灣 99 筆，占 66%；國際 51 筆，占 34%），9、10、11、12 月分別覆蓋 30、31、30、31 天，每天 1～3 筆；另保留原有 2/28 紀事。原有九二一地震、故宮開館等重大台灣事件保留。

## 取材與來源

- 優先台灣與國際重大事件，包含政治制度、戰爭與和平、人權、科學突破、公共建設及重要文化體育成果。
- 人物出生只選具有重要歷史影響的人物，目前收錄劉銘傳、郭台銘、何大一與孫中山，摘要明確說明其歷史、產業或醫學影響。未使用一般藝人生日補齊日期。
- 每天依重要性選 1～3 則，不為湊滿欄位而補入次要事件。占比以整份資料的紀事筆數計算，並非要求每一天都固定配置兩則台灣、一則國際。
- `region` 為「台灣」或「國際」，用於卡片標示；同一天優先列台灣事件，再列國際事件。台灣類包含對台灣政治、社會或產業具有直接影響的事件及人物，不以事件發生地或人物出生地作為唯一判準。
- 本輪依台灣占比 66% 調整：新增 34 筆台灣紀事、精簡 24 筆國際紀事；保留九一一攻擊、柏林圍牆開放、巴黎協定等重要國際事件。新增資料查閱維基百科、中央研究院、檔案管理局、交通部、總統府、立法院及中央社等來源。
- 校對時排除日期混淆：中山高速公路全線通車為 1978/10/31；雪山隧道貫通為 2004/9/16；中美共同防禦條約採華府簽署日 1954/12/2；1978 年美國宣布斷交則明示台灣時間 12/16。
- 透過網路搜尋與維基百科日期頁尋找候選，再查閱主題條目及可取得的政府、機構或新聞資料，確認年月日與事件性質。並非每筆都有兩個獨立來源。
- 每筆 `source`、`sourceUrl` 指向可供查閱的來源，摘要以繁體中文重新撰寫，人物紀事中後來的成就與當日出生事件分開表述。
- 保留歷史紀事的來源欄位；其他日曆資料不帶來源的設定不受影響。
- 新增國際紀事逐日查閱英文維基百科日期頁，並以聯合國、UNICEF、UNESCO、NASA、CERN 等官方紀錄補充核對重要事件。日期頁可能有不精確表述，因此區別通過、簽署與生效，例如世界人權宣言是聯合國大會通過的宣言，並非簽署生效的條約。
- 國際事件通常採事件所在地的通行歷史日期；珍珠港襲擊明示夏威夷當地日期。台北暗殺星奪冠則保留台灣時間並在摘要註明，不將所有海外事件一律換算成台灣日期。

## 檢查

`npm run data:check-history` 檢查資料欄位、有效日期、摘要長度、分類、HTTPS 網址格式、重複紀事、每日最多三則及 9～12 月逐日覆蓋。此命令不驗證網址連線或史實；史實仍需查閱每筆來源。

瀏覽器測試涵蓋 1920×1080 三欄並排且不增加垂直捲動、手機版、離線跨日由 9/21 切換至 9/22，以及實際 MV3 載入。其他月份尚未覆蓋的日期仍保留空狀態。
