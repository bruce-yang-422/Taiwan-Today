- 有些台詞表達角色的偏見、取捨或矛盾，供省思，不視為作者主張或一律適用的行事準則；相關條目在 `sourceWork` 補充語境。例如《進擊的鼓手》的訓練觀點、《復仇者聯盟：無限之戰》的 Thanos 台詞。
- 新增內容按來源頁合計節錄不超過 25 個英文詞；保留來源連結供閱讀上下文。原有 33 則的來源及整理方式見 [先前清單紀錄](screen-review.md)。
