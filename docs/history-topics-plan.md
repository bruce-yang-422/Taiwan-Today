# 歷史主題資料集：預留介面

狀態：僅預留程式介面，尚未實作主題選擇、匯入、下載或主題內容。

## 資料介面

`src/calendar/history.ts` 提供：

- `HistoryEntry`：沿用日期、年份、標題、摘要、地區及選填來源欄位，新增選填 `tags` 字串陣列。
- `HistoryDataset`：`id`（穩定識別碼）、`label`（顯示名稱）、`kind`（personal／regional／topic）、`entries`（紀事陣列）。
- `historyDatasets`：目前只登錄個人、台灣、國際三份本機 JSON，順序維持原顯示優先順序。
- `composeHistory(datasets)`：合併已提供的資料集，保留資料集與紀事順序；不負責下載、儲存或切換設定。

既有 JSON 維持陣列格式，不需加上資料集外層，也不用補 `tags`。資料集名稱與事件地區分開：例如科技主題中的台灣事件仍填 `region: "台灣"`，不將地區改成「科技」。

## 未來實作接點

1. 各主題新增獨立 JSON 紀事陣列，透過 `HistoryDataset` 登錄，避免修改台灣／國際／個人資料。
2. 決定選取介面、設定儲存與是否允許多選後，再將選中的資料集交給 `composeHistory`。
3. 動態切換須同步重建 `dailyCalendar.ts` 的日期索引，並使畫面重新渲染；目前索引在模組載入時建立，尚不支援執行中切換。
4. 主題可能和地域資料重疊，正式實作時須決定穩定事件 ID、跨資料集去重及每日顯示筆數；目前仍維持每日最多三則。
5. 補上主題資料驗證規則。現有 `data:check-history` 的 9～12 月覆盖與台灣占比統計只針對公開地域資料，不應直接套用到各主題。
6. 日期須區分發表、上市、首播、首映與地區版本，引用可查證來源；目前不新增未查核事件。

目前沒有主題 JSON 空檔、網路載入、額外權限或設定選項。CSV／XLSX 工具維持現有私人紀事轉換功能，尚不提供主題分類與 tags 編輯。
