    2 預覽與下載

    尚無紀事

    有錯誤時不產生部分檔案；修正表格後重新選取。相同日期、年份與標題的資料視為重複。

    表格欄位怎麼填？
    欄位（英文亦可）填寫方式
    日期 / date *09-21、9/21 或完整日期 2010-09-21；支援 Excel 日期儲存格。
    年份 / year西元年，例如 2010。使用完整日期時可省略，兩者皆填須一致。
    標題 / title *例如「搬進第一個家」。
    摘要 / summary *記錄當天發生的事。
    分類 / region個人、家族、台灣或國際；空白使用上方選項。
    關鍵字 / keyword選填；有填才會在插件顯示 Google「深入了解」。
    來源 / source選填；例如「家庭相簿」，空白會填「私人紀事」。
    來源網址 / sourceUrl選填；僅接受 HTTPS 網址，不必為私人回憶提供公開連結。

    下載後，如何放進插件？

    下載 history-personal.json 後，開啟插件新分頁的「設定 → 匯入個人歷史 JSON」。選取檔案，確認筆數與預覽後，按「匯入並取代」即可立即套用，不需要修改程式或重新建置。

    匯入會取代目前的個人紀事，可先按「匯出目前紀事備份」保存舊資料。紀事僅存在本機，重新開頁仍會保留；移除擴充功能會清除資料。匯入空陣列 [] 可清空個人紀事。

    預設私人 → 台灣 → 國際，可在「設定 → 紀事來源與順序」開關來源並調整順序，預設顯示三則，可按「顯示更多」查看當天全部紀事；未來年份的紀事不會提前顯示。若自行合併 JSON，請將想優先顯示的紀事排在前面。

    私人檔案請留在自己的裝置，不必提交到 GitHub，也不會由此工具上傳。
